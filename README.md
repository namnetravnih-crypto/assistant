# Ассистент — тренировочная студия

Статический сайт (HTML + CSS + JS), серверная часть не нужна. Две программы под одним входом:

- **Stamp Studio** (`stamp.html`) — очистка изображений оттисков, работа с подписью, экспорт PNG.
- **Автозаполнение документов** (`docs.html`) — заполнение заявок, анкет, договоров и спецификаций по реквизитам Заказчика и Участника / Исполнителя.

Предназначен для тренировки, обучения и создания макетов.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него **всё содержимое этой папки** (включая `assets/` и `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Нужен интернет только для шрифтов Google Fonts и pdf.js (чтение PDF с реквизитами); остальные библиотеки лежат в `assets/vendor/`.

## Структура
```
index.html            главная: выбор программы
stamp.html            Stamp Studio
docs.html             автозаполнение (4 блока)
assets/css/           theme.css (дизайн и подсказки), portal.css, stamp.css, docs.css, overlay.css
assets/js/stamp.js    редактор оттисков + кнопка «Добавить в файл»
assets/js/stampcache.js  кэш печати в браузере на 30 минут
assets/js/engine.js   движок заполнения DOCX / XLSX (реквизиты, подписанты, КС)
assets/js/tech.js     ТЗ → техническое предложение («не менее», «не более» и др.)
assets/js/overlay.js  наложение печати 40 мм мышью, экспорт в DOCX / XLSX и «изображение в PDF»
assets/js/docs.js     интерфейс четырёх блоков
assets/js/tips.js     всплывающие подсказки для учеников
assets/vendor/        jszip, docx-preview, html2canvas, pdf-lib
```

## Блоки автозаполнения
1. **Трудовой договор** — реквизиты работодателя и работника (вручную или из .docx/.xlsx/.pdf/.txt) → бланк договора.
2. **Формы и договоры** — прежний функционал: заявки, анкеты, договоры, спецификации.
3. **Техническое предложение** — окно ТЗ и окно предложения; показатели ТЗ заменяются в предложении на конкретные значения с сохранением структуры и стиля. Для «от … до …» можно выбрать границу или середину.
4. **КС-2, КС-3** — окна «Заказчик (Генподрядчик)» и «Подрядчик (Субподрядчик)», окно загрузки Excel; заменяются реквизиты сторон и подписанты «Сдал / Принял».

В каждом блоке сверху — галочка «Выделять жёлтым цветом не заполненные поля» (включена по умолчанию); в конце — кнопки «Скачать», «Скачать изображение в PDF» и блок «Наложение печати».

## Печать
В Stamp Studio кнопка «Добавить в файл» сохраняет готовую печать в память браузера на 30 минут (потом стирается сама). В блоках автозаполнения печать 40 мм ставится кликом на предпросмотре документа, можно несколько раз, и перетаскивается мышью. Положение в Word рассчитано по абзацу — при другой разбивке на страницы проверьте результат.

## Автозаполнение: как это работает
- Две стороны: окно «Реквизиты Заказчика» и окно «Реквизиты Участника / Исполнителя». Карту можно загрузить (.docx, .xlsx, .pdf с текстом, .txt), вставить текстом или ввести вручную.
- В договорах сторона определяется по тексту: «…, именуемое «Заказчик», в лице …», по заголовкам «ЗАКАЗЧИК / ИСПОЛНИТЕЛЬ» и по колонкам таблицы реквизитов. В формах участника всё заполняется за Участника.
- «В лице …»: родительный падеж должности и ФИО подставляется автоматически, его можно поправить вручную.
- Спецификации: сумма по позиции = количество × цена, затем «ИТОГО» и «В том числе НДС» (ставка 22 / 10 / 0 %). Если цен нет — пустые цены подсвечиваются.
- То, что программа не смогла заполнить, подсвечивается жёлтым. Правила эвристические — результат нужно проверять.
- Ограничения: старые форматы .doc / .xls и сканы PDF не поддерживаются.
