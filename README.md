# АССИСТЕНТ — творческое пространство

Статический сайт (HTML + CSS + JS), серверная часть не нужна. Светлое оформление. Две программы под одним входом:

- **Stamp Studio** (`stamp.html`) — очистка изображений оттисков, экспорт PNG. Работа с подписью по умолчанию выключена: включается галочкой на шаге 3, подпись отмечается кистью по её линии (цвет подписи часто совпадает с цветом оттиска, поэтому по цвету она не ищется).
- **Автозаполнение документов** (`docs.html`) — заполнение заявок, анкет, договоров и спецификаций по реквизитам Заказчика и Участника / Исполнителя.

Предназначен для тренировки, обучения и создания макетов.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него **всё содержимое этой папки** (включая `assets/` и `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Нужен интернет: шрифты Google Fonts, JSZip и pdf.js подгружаются с CDN (при недоступности используются системные шрифты).

## Структура
```
index.html            главная: выбор программы
stamp.html            Stamp Studio
docs.html             автозаполнение
assets/css/           theme.css (общий дизайн), portal.css, stamp.css, docs.css
assets/js/stamp.js    редактор оттисков
assets/js/engine.js   движок заполнения DOCX / XLSX
assets/js/docs.js     интерфейс автозаполнения
```

## Автозаполнение: как это работает
- Две стороны: окно «Реквизиты Заказчика» и окно «Реквизиты Участника / Исполнителя». Карту можно загрузить (.docx, .xlsx, .pdf с текстом, .txt), вставить текстом или ввести вручную.
- В договорах сторона определяется по тексту: «…, именуемое «Заказчик», в лице …», по заголовкам «ЗАКАЗЧИК / ИСПОЛНИТЕЛЬ» и по колонкам таблицы реквизитов. В формах участника всё заполняется за Участника.
- «В лице …»: родительный падеж должности и ФИО подставляется автоматически, его можно поправить вручную.
- Спецификации: сумма по позиции = количество × цена, затем «ИТОГО» и «В том числе НДС» (ставка 22 / 10 / 0 %). Если цен нет — пустые цены подсвечиваются.
- То, что программа не смогла заполнить, подсвечивается жёлтым. Правила эвристические — результат нужно проверять.
- Ограничения: старые форматы .doc / .xls и сканы PDF не поддерживаются.
